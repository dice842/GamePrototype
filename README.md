# GamePrototype

Unity와 C#을 학습하며 제작한 2D 탑다운 액션 게임 프로토타입입니다.

플레이어 이동과 스태미너, 총기와 투척물, 적 AI 등 여러 게임 기능을 구현하고 테스트했습니다.

프로젝트 개발은 이후 중단되었으며, 구현했던 기능과 아이디어 일부는 다른 프로젝트로 발전하여 사용되었습니다.

## 개발 환경

- Unity 2022.3.7f1
- C#

## 주요 기능

- 플레이어 이동, 달리기 및 대시
- 스태미너 관리
- 총기 사격 및 재장전
- 무기와 탄약 종류에 따른 능력치 관리
- 수류탄 및 연막탄 투척
- 적 체력 및 피격 처리
- GOAP를 이용한 적 AI 기능 테스트

## Scripts

### PlayerControl.cs
플레이어의 이동 입력과 무기 및 투척물 사용을 관리합니다.

### PlayerMove.cs
플레이어의 걷기, 달리기, 대시 등의 이동 기능을 처리합니다.

### PlayerAdility.cs
플레이어의 체력과 스태미너 등의 능력치를 관리합니다.

### Weapon.cs
총기의 사격, 탄약, 재장전, 명중률과 공격 처리를 담당합니다.

### WeaponTypes.cs
총기별 사거리, 연사속도, 장탄수 등의 정보를 관리합니다.

### BulletTypes.cs
탄약의 공격력, 사거리 등의 정보를 관리합니다.

### ThrownWeapons.cs
투척물의 투척 방향과 세기를 계산하고 생성합니다.

### Grenades.cs
수류탄의 폭발과 범위 피해를 처리합니다.

### SmokeGrenades.cs
투척 후 일정 시간이 지나면 연막을 생성합니다.

Note

여러 게임 시스템을 구현하고 테스트하기 위해 제작한 프로토타입 프로젝트입니다.

개발이 중단된 이후 일부 기능과 아이디어는 다른 프로젝트에 병합되었으며, 현재 저장소는 당시의 학습 및 개발 과정을 기록하기 위해 유지하고 있습니다.
